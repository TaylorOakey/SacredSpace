# Sacred Codex — Web UI Kit

## Surface
The **Web Experience** — a ritual portal where seekers explore the Arcana, discover their archetype, and enter the living codex.

## Design Width
1280px desktop. Mobile breakpoints at 768px and 375px.

## Core Screens
1. **Portal / Landing** — Hero with Metatron's Grid, entry invocation, CTA
2. **Arcana Map** — Interactive 3×4 grid of all 12 Archetypes
3. **Archetype Detail** — Full codex entry for a single Archetype
4. **Codex Reader** — Two-column codex-style reading experience

## Component Index
- `SacredNav` — Top navigation with gold rule underline
- `HeroPortal` — Full-viewport landing with geometric animation
- `ArcanaGrid` — Interactive 3×4 lattice with hover reveals
- `ArchetypeCard` — Portrait card (used in grid and detail)
- `CodexEntry` — Two-column marginalia layout
- `CipherBlock` — Monospace sacred data block
- `SacredNode` — Concentric ring badge
- `ElementTag` — Element/Prime label pills
- `Footer` — Sacred seal footer

## Notes
- All transitions: 400–700ms ease-in-out
- No rounded corners on cards/panels (0px)
- Gold hairline rules used for all dividers
- Parchment `#F4ECD8` is always the base; Void `#0B0A0F` for Metatron sections
- Fonts loaded from Google Fonts: Cinzel, IM Fell English, EB Garamond, JetBrains Mono
