## 1. CORE VISUAL PILLARS

The visual environment of SacredSpace merges the **ancient with the hyper-futuristic**. It is *impossible nature* — where organic flow meets crystalline precision.

### Color
- Deep, dark-matter backgrounds (`#05060A · #0A0F1C · #0D1B14`)
- Highly saturated luminous accents:
  - **Cyan-Blue** `#00E5FF` — electricity, signal, awakening
  - **Soft Magenta** `#FF00FF` / `#E869F0` — Priestess threshold, mystery
  - **Bioluminescent Green** `#7FFFD4` / `#4EFFA1` — living forest, the grove
  - **Sacred Gold** `#F0C75E` — preserved from Codex DNA, the Law
  - **Arcane Violet** `#B48EF7` — sigil glow, types, archetype identity
- Sacred Codex parchment + ink retain as **printed/codex-mode only** — digital surfaces are luminous-dark by default

### Lighting
- Subsurface scattering — light emanates **from within** data structures, not upon them
- Glassmorphism — frosted panels over deep, alive backgrounds
- Ethereal glows on every interactive surface (hover = bloom)

### Texture
- Layered translucent scenery (clouds-as-marble, water-as-glass)
- Stone engraved with glowing circuitry / sacred murals
- Bio-organic forms with crystalline edges

## 2. SIGILIFY 2.0 — LUMINOUS UI

Hyperglyphs (`∆ ◇ ✶ ◯ △ ▽ ⊕ ◈ ⬡ ∞`) evolve from static text into **living luminous elements**.

### Hyperglyph Styling Rules
- Apply CSS `text-shadow` chromatic-aberration: `1px 0 0 cyan, -1px 0 0 magenta, 0 0 12px gold`
- On hover/activation: pulse animation + neon-pastel gradient shift
- Active state: full chromatic bloom with `filter: drop-shadow()`
- Idle state: subtle 3% opacity ambient glow

### Glassmorphic Panel Spec
```css
background: rgba(10, 15, 28, 0.55);
backdrop-filter: blur(24px) saturate(1.4);
border: 1px solid rgba(127, 255, 212, 0.18);
box-shadow:
  inset 0 1px 0 rgba(255, 255, 255, 0.08),
  0 8px 60px rgba(0, 229, 255, 0.08),
  0 0 0 1px rgba(180, 142, 247, 0.12);
```

The Sacred Command Board, all UI cards, and panel surfaces use this base.

## 3. HOLOGRAPHIC MEMORY VISUALIZATION

Memory Motes and knowledge nodes are not rows of data — they are **living flora** within the ecosystem.

### The Neural Forest
- Data clusters render as glowing, bio-organic trees or floating crystalline islands
- Each Mote has: **glyph · color signature · pulse rate · decay state**
- Connections between motes draw as luminous filaments — gradient cyan→magenta→gold

### Ebbinghaus Decay in Color
| State | Age | Saturation | Glow | Color Shift |
|---|---|---|---|---|
| **Fresh** | < 1h | 100% | Bright bloom | Full cyan/magenta/green |
| **Warm** | 1h – 1d | 85% | Soft bloom | Slight desaturation |
| **Cooling** | 1–7d | 60% | Faint glow | Cooler pastel |
| **Decayed** | 7–30d | 35% | Ambient only | Ghost-pastel, translucent |
| **Dormant** | > 30d | 15% | None | Gray-violet whisper |

Refresh on access → returns to Fresh state, full saturation.

### Depth & Parallax
- Min 3 background layers, scrolling at 0.2x / 0.5x / 1.0x rates
- Mid-layer: floating geometric motes drifting upward
- Far-layer: nebular gradients, soft cloud forms
- Near-layer: foreground sigils + glassmorphic panels
