2. Home screen & launcher gestures

On Android (Moto G Stylus), the easiest custom gestures usually come from:

A custom launcher like Nova Launcher or Niagara Launcher
→ These let you assign swipes, double-taps, pinches to apps.


I’d suggest installing Nova Launcher and doing this:

A. Dock = “Sacred Row”

Bottom row icons (always visible):

1. ChatGPT


2. Google Docs


3. Obsidian


4. NotebookLM (as a PWA shortcut from Chrome)


5. Drive



So even with no gestures, you’ve got 1-tap access to the full brain.

B. Icon swipe gestures

In Nova, you can assign swipe up on an icon to a different action:

For example:

Swipe up on ChatGPT icon → open a specific “SacredSpace Guardian” chat

Swipe up on Google Docs icon → “New document” shortcut

Swipe up on Obsidian icon → open your “Daily Sacred Log” note

Swipe up on NotebookLM icon → open your “SacredSpace Project” notebook

Swipe up on Drive icon → open “SACREDSPACE Master Folder”


So tap = app, swipe = your most-used within that app.

C. Home-screen gestures

In Nova you can set gestures on empty space:

Double-tap home screen → open ChatGPT

Swipe up on home → open NotebookLM

Swipe down on home → open Obsidian

Pinch-out (two fingers apart) → open Google Docs

Pinch-in (two fingers together) → open Drive or SacredSpace folder


That gives your thumbs a “ritual”:

Up = research brain

Down = vault

Pinch = documents / archive

Double-tap = talk to Bodhi 😄
