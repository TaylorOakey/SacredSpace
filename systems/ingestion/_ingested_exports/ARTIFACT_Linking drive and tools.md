# **THE SHORT, CLEAN TO-DO LIST**

## **1. Set up Google Drive as your “Master Vault”**
This is the one folder everything else will read from.

**You must:**  
1. Make a main folder in Drive called **Digital Sacred Sanctuary** (or use the one you already have).  
2. Put your Google Docs, PDFs, game files, story drafts, etc. inside that folder.

Nothing else works until this foundation is set.

---

# **2. Connect LM Notebook to Google Drive**
This lets LM Notebook “see” your Drive files.

**Steps:**  
1. Open **notebooklm.google.com**  
2. Create a new notebook  
3. Click **Add Source → Google Drive → (choose the Sacred Sanctuary folder)**  
4. Confirm permissions.

Once that’s done, LM Notebook can reference everything.

---

# **3. Connect AI Studio to Google Drive**
This lets AI Studio agents read your files.

**Steps:**  
1. Open **aistudio.google.com**  
2. Create or open your SacredSpace Agent  
3. On the right side, find **“Add data source”**  
4. Choose **Google Drive**  
5. Select the same Sacred Sanctuary folder  
6. Approve permissions fully

Now both LM Notebook and AI Studio pull from the same Drive vault.

---

# **4. Sync Obsidian with that SAME Drive folder**
This lets your offline/desktop notes talk to your online notes.

You are doing this with **Syncthing**, since you don’t want to pay for Obsidian Sync.

### **Syncthing Setup (simple version):**
You need Syncthing on:
- the Library PC  
- your Moto G Stylus  

**Steps:**  
1. Install Syncthing on both devices  
2. On the computer:  
   - Open Syncthing  
   - Create a shared folder → point it to your **Obsidian Vault folder**  
   - Get the device ID  

3. On the phone:  
   - Install Syncthing  
   - Add the computer’s device ID  
   - Accept the shared folder  
   - Sync it to Internal Storage → “Obsidian Vault”  

4. Inside that Obsidian Vault, make a folder called **DriveBridge**  
5. Inside DriveBridge, store shortcuts or exported versions of your Drive docs.

Now Obsidian stays in sync with your computer AND your phone.
